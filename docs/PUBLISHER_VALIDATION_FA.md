# اعتبارسنجی شبکهٔ تبلیغاتی برای جایگاه ادیتور

کد نمودارا برای بارگذاری تبلیغ داخل Frame جدا آماده است، اما تأیید نهایی سازگاری باید با **شناسه‌های واقعی حساب ناشر نمودارا** و پاسخ پشتیبانی شبکه انجام شود. رفتار یکتانت یا تپسل ممکن است براساس نوع جایگاه، دامنه، قوانین حساب و نسخهٔ اسکریپت متفاوت باشد.

## پیام پیشنهادی برای پشتیبانی یکتانت یا تپسل

```text
سلام

سایت ما یک ابزار تحت وب در دامنه nemodara.ir است. برای حفظ حریم خصوصی کد کاربران،
جایگاه تبلیغ ادیتور را داخل iframe با Origin جدا در ads.nemodara.ir نمایش می‌دهیم.
اسکریپت سراسری ناشر و div جایگاه هر دو داخل همان سند iframe قرار می‌گیرند.

لطفاً تأیید کنید:
1. آیا نمایش جایگاه وب داخل iframe و روی ساب‌دامین ثبت‌شده مجاز و قابل گزارش است؟
2. آیا لازم است ads.nemodara.ir جداگانه به رسانه یا دامنه‌های مجاز حساب اضافه شود؟
3. برای ستون 300px دسکتاپ چه فرمت یا جایگاهی پیشنهاد می‌کنید؟
4. برای نوار responsive موبایل/لپ‌تاپ چه فرمت یا جایگاهی پیشنهاد می‌کنید؟
5. آیا کلیک تبلیغ در iframe sandbox با allow-popups و
   allow-popups-to-escape-sandbox به‌درستی ثبت و باز می‌شود؟
6. آیا محدودیت خاصی برای referrerPolicy=origin یا CSP وجود دارد؟
7. آیا اسکریپت شما به دسترسی به window.top، parent DOM یا Local Storage دامنهٔ اصلی نیاز دارد؟
8. چه روشی برای تست جایگاه بدون ایجاد کلیک نامعتبر پیشنهاد می‌کنید؟

دامنه اصلی: https://nemodara.ir
دامنه frame: https://ads.nemodara.ir
```

پاسخ پشتیبانی را همراه تاریخ در اسناد داخلی یا Annotation پنل ثبت کنید.

## فرمت‌های موردنیاز

برای شروع دو Placement مستقل در پنل بسازید:

```text
editorRail    ستون دسکتاپ، عرض هدف 300px
editorDock    بنر responsive زیر ادیتور، ارتفاع تقریبی 90 تا 110px
```

از یک Placement ID برای هر دو اندازه استفاده نکنید مگر خود پنل شبکه آن جایگاه را Responsive معرفی کرده باشد. گزارش جدا به تشخیص eCPM، CTR و Fill Rate هر سطح کمک می‌کند.

## تست فنی بدون کلیک روی تبلیغ خودتان

1. جایگاه را ابتدا روی محیط محدود یا rollout ده درصد فعال کنید.
2. بازشدن اسکریپت، درخواست‌های شبکه و محتوای Frame را در DevTools بررسی کنید.
3. مطمئن شوید در Console والد CSP Error مربوط به شبکه وجود ندارد.
4. در پنل ناشر، Impression و Fill جایگاه را بعد از بازهٔ به‌روزرسانی گزارش بررسی کنید.
5. برای تست Click از Preview یا ابزار رسمی شبکه و همکاری پشتیبانی استفاده کنید؛ روی تبلیغ زندهٔ خودتان کلیک نکنید.
6. Publisher Script نباید در فهرست Scriptهای Document اصلی `/editor` دیده شود.
7. در Frame نباید متن Mermaid، CodeMirror یا Local Storage دامنهٔ اصلی قابل خواندن باشد.
8. اگر شبکه برای نمایش به دسترسی `window.top` یا Parent DOM نیاز دارد، جایگاه را فعال نکنید و از یک فرمت سازگار درخواست کنید.

## معیار پذیرش

جایگاه زمانی آمادهٔ rollout است که:

- روی Desktop و Mobile محتوای واقعی نمایش دهد؛
- Impression در پنل ناشر ثبت شود؛
- خطای CSP یا JavaScript نداشته باشد؛
- لینک تبلیغ با رفتار مورد تأیید شبکه باز شود؛
- فاصلهٔ مستقل از دکمه‌های Export و کنترل‌های ادیتور داشته باشد؛
- CLS و INP افت معنادار نداشته باشند؛
- نرخ `ad_script_error` و `ad_blocked` قابل توضیح باشد؛
- پشتیبانی شبکه استفاده از Frame و ساب‌دامین را رد نکرده باشد.

## معیار رد یا توقف

- عدم ثبت Impression با وجود نمایش ظاهری
- نیاز اسکریپت به Parent DOM یا متن صفحه
- درخواست غیراستاندارد برای حذف Sandbox یا Cross-Origin isolation
- بازشدن کلیک داخل خود Frame یا شکستن ناوبری
- افزایش کلیک‌های تصادفی
- اخطار سیاست، ترافیک نامعتبر یا نمایش روی دامنهٔ ثبت‌نشده
- افت پایدار تجربهٔ ادیتور

در این حالت:

```dotenv
ADS_EDITOR_ENABLED=false
```

یا فقط rollout را متوقف کنید:

```dotenv
ADS_EDITOR_TRAFFIC_PERCENT=0
```

جایگاه‌های محتوایی می‌توانند مستقل از ادیتور فعال باقی بمانند.
