# Mermaid Studio — راهنمای فارسی محصول

Mermaid Studio یک استودیوی متن‌باز برای ساخت و خروجی گرفتن از نمودارهای Mermaid است. این نسخه شامل صفحه معرفی فارسی، ادیتور راست‌به‌چپ، رابط محلی/آفلاین، CLI و API رندر محافظت‌شده است.

## شروع سریع

```bash
npm install
npm run serve
```

پس از اجرا:

- صفحه معرفی محصول: `http://127.0.0.1:4321/`
- ادیتور: `http://127.0.0.1:4321/editor`
- سلامت سرویس: `http://127.0.0.1:4321/api/health`

## امکانات نسخه فارسی

- صفحه فرود فارسی و واکنش‌گرا
- ادیتور فارسی با حفظ جهت چپ‌به‌راست برای کد
- تم روشن و تیره
- پیش‌نمایش زنده و تشخیص نوع نمودار
- خروجی SVG، PNG، JPG، WebP و PDF
- صفحات حریم خصوصی و قوانین استفاده
- لینک اشتراک‌گذاری بدون حساب کاربری
- PWA manifest و لوگوی مستقل

## انتشار نهایی با Docker Compose

برای اجرای production همراه با HTTPS خودکار:

```bash
cp .env.example .env
docker compose build --pull
docker compose up -d
```

چک‌لیست کامل در [`docs/PRODUCTION_CHECKLIST_FA.md`](docs/PRODUCTION_CHECKLIST_FA.md) قرار دارد.

## استقرار روی سرور

متغیرهای محیطی مهم در فایل `.env.example` مستند شده‌اند. برای نسخهٔ عمومی، حداقل این موارد را تنظیم کنید:

```bash
NODE_ENV=production
HOST=0.0.0.0
PORT=4321
MSTUDIO_PUBLIC_MODE=1
MSTUDIO_ALLOW_UNSAFE_MERMAID=0
```

راهنمای کامل در [`docs/DEPLOYMENT_FA.md`](docs/DEPLOYMENT_FA.md) قرار دارد.

## مدل درآمدی: رایگان و تبلیغاتی

تمام قابلیت‌های اصلی Mermaid Studio رایگان باقی می‌مانند و برنامه اشتراک یا پلن پولی ندارد. درآمد نسخهٔ آنلاین از جایگاه‌های تبلیغاتی مشخص‌شده در صفحهٔ اصلی، قالب‌ها و آموزش‌ها تأمین می‌شود. برای محافظت از کد کاربر، اسکریپت تبلیغاتی داخل ادیتور بارگذاری نمی‌شود.

راهنمای اتصال یکتانت و تپسل در [`docs/ADS_FA.md`](docs/ADS_FA.md) قرار دارد.

## حریم خصوصی و امنیت

- پیش‌نمایش و SVG در مرورگر تولید می‌شوند.
- خروجی‌های raster و PDF ممکن است برای پردازش موقت به سرور ارسال شوند.
- برنامه کد نمودار را به‌صورت دائمی در پایگاه داده ذخیره نمی‌کند.
- لینک اشتراک‌گذاری، وضعیت را در hash آدرس نگه می‌دارد.
- Mermaid در نسخهٔ عمومی با `securityLevel: strict` اجرا می‌شود.
- API رندر دارای محدودیت حجم، نرخ درخواست، صف و هم‌زمانی است.

## تست

```bash
npm test
npm run test:product
```

تست محصول مسیرهای فارسی، هدرهای امنیتی، متادیتا و محدودیت حجم API را بررسی می‌کند.

## گام‌های پیشنهادی بعدی

1. انتشار مقاله‌های فارسی مستقل برای هر نوع نمودار
2. افزایش تعداد قالب‌های کاربردی قابل ویرایش
3. اتصال شناسه‌های واقعی یکتانت یا تپسل پس از تأیید دامنه
4. اندازه‌گیری سرعت، بازگشت کاربر و درآمد واقعی هر جایگاه
5. ادامهٔ کاهش مصرف رندر سروری برای کنترل هزینهٔ هاست
