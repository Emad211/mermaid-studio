سیاست حریم خصوصی

آخرین به‌روزرسانی: ۲۲ تیر ۱۴۰۵

اصل کلی

Mermaid Studio با رویکرد «حداقل‌سازی داده» طراحی شده است. استفادهٔ عادی به حساب کاربری نیاز ندارد و کد نمودار به‌صورت دائمی در پایگاه داده ذخیره نمی‌شود.

کد و محتوای نمودار

پیش‌نمایش و بیشتر خروجی‌های تصویری در مرورگر شما ساخته می‌شوند. برای خروجی PDF یا استفاده از API رندر، کد فقط برای انجام همان درخواست به سرور ارسال می‌شود. برنامه نباید متن نمودار یا بدنهٔ درخواست رندر را در گزارش‌های تحلیلی ثبت کند.

لینک اشتراک‌گذاری

کد و تنظیمات لینک اشتراک‌گذاری به‌صورت فشرده داخل بخش Hash آدرس قرار می‌گیرند. این بخش معمولاً در درخواست HTTP به سرور ارسال نمی‌شود. هر فرد دارای لینک می‌تواند محتوا را مشاهده کند؛ اطلاعات محرمانه را در لینک عمومی قرار ندهید.

آنالیز بازدید و عملکرد محصول

نسخهٔ عمومی می‌تواند از تحلیل first-party و بدون سرویس خارجی برای اندازه‌گیری بازدید صفحه، جلسه، کاربر یکتای روزانه، مدت تعامل، ورود به ادیتور، موفقیت رندر، نوع خروجی، منبع ارجاع، پارامترهای UTM، نوع دستگاه و Core Web Vitals استفاده کند.

  • IP خام، متن نمودار، کد Mermaid، محتوای فایل و متن کلیپ‌بورد ذخیره نمی‌شود.
  • شناسهٔ دائمی کاربر ساخته نمی‌شود؛ برای تخمین کاربر یکتای روزانه از HMAC روزانه و غیرقابل بازیابی استفاده می‌شود.
  • پارامترهای کامل URL ذخیره نمی‌شوند و فقط UTMهای متعارف کمپین ثبت می‌شوند.
  • سیگنال‌های Do Not Track و Global Privacy Control به‌طور پیش‌فرض محترم شمرده می‌شوند.
  • دادهٔ Web Vitals به‌صورت نمونه‌های عددی و تجمیعی نگهداری می‌شود.

درآمد و داده‌های پنل ناشر

عدد درآمد، نمایش و کلیک ممکن است به‌صورت دستی یا با CSV از گزارش پنل یکتانت یا تپسل وارد داشبورد خصوصی شود. این داده‌ها تجمیعی‌اند و شامل هویت بازدیدکننده یا محتوای تبلیغ مشاهده‌شده نیستند.

تبلیغات شخص ثالث

تبلیغات فقط در صفحات محتوایی مانند خانه، قالب‌ها و آموزش نمایش داده می‌شوند. ادیتور و رندرکنندهٔ headless اسکریپت تبلیغاتی بارگذاری نمی‌کنند. شبکهٔ ناشر ممکن است براساس سیاست خودش IP، مرورگر، شناسه‌های تبلیغاتی یا Cookie را برای تحویل، شمارش، جلوگیری از تقلب و گزارش تبلیغ پردازش کند.

تا زمانی که اطلاعات معتبر پنل ناشر و گزینهٔ فعال‌سازی تنظیم نشده باشد، هیچ درخواست تبلیغاتی شخص ثالث ارسال نمی‌شود. جایگاه‌ها با برچسب «تبلیغات» مشخص‌اند و پاپ‌آپ یا کلیک اجباری استفاده نمی‌شود.

گزارش‌های فنی و امنیت

سرور میزبان یا reverse proxy ممکن است برای امنیت، تشخیص حمله و رفع خطا زمان درخواست، مسیر، وضعیت پاسخ و IP را برای مدت محدود در access log نگه دارد. بدنهٔ درخواست و کد Mermaid نباید وارد این لاگ‌ها شود.

مدت نگهداری و دسترسی مدیریتی

دادهٔ تحلیلی تجمیعی به‌طور پیش‌فرض حداکثر ۴۰۰ روز نگهداری می‌شود و مدیر سرور می‌تواند این بازه را کمتر کند. داشبورد درآمد و بازدید عمومی نیست و با احراز هویت محافظت می‌شود.

نسخهٔ محلی

نسخهٔ CLI و سرور محلی را می‌توانید روی رایانه یا زیرساخت خودتان اجرا کنید. در آن حالت، مدیریت داده، تبلیغات و گزارش‌ها کاملاً تحت کنترل شماست.

تماس و تغییرات

برای گزارش امنیتی از بخش Security مخزن و برای پیشنهاد عمومی از Issues استفاده کنید. تغییرات مهم این سیاست با تاریخ جدید در همین صفحه منتشر می‌شود.
