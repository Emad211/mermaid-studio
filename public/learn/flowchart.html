رسم فلوچارت با Mermaid

فلوچارت برای نمایش ترتیب مراحل، تصمیم‌ها و مسیرهای یک فرایند مناسب است. در Mermaid هر گره با یک شناسه تعریف می‌شود و پیکان‌ها ارتباط میان گره‌ها را نشان می‌دهند.

زمان مطالعه: ۸ دقیقهسطح: مقدماتیمثال‌های قابل ویرایش

اولین فلوچارت

خط اول نوع نمودار و جهت آن را مشخص می‌کند. در نمونهٔ زیر، TD یعنی نمودار از بالا به پایین رسم شود.

نمونهٔ پایهویرایش در ادیتور
flowchart TD
    A[شروع] --> B[دریافت اطلاعات]
    B --> C[پردازش]
    C --> D[پایان]

انتخاب جهت نمودار

بعد از واژهٔ flowchart یکی از جهت‌های زیر را بنویس:

  • TD یا TB: بالا به پایین
  • LR: چپ به راست
  • RL: راست به چپ
  • BT: پایین به بالا
نکته: برای نمودارهای عریض معماری، معمولاً LR خواناتر است؛ برای فرایندهای مرحله‌ای، TD انتخاب خوبی است.

شکل گره‌ها

نوع براکت ظاهر گره را تغییر می‌دهد. مستطیل برای فعالیت، لوزی برای تصمیم و گوشه‌گرد برای شروع یا پایان رایج است.

گره‌ها و شرطویرایش در ادیتور
flowchart TD
    A([شروع]) --> B[ثبت سفارش]
    B --> C{پرداخت موفق بود؟}
    C -- بله --> D[ارسال سفارش]
    C -- خیر --> E[تلاش دوباره]
    E --> C
    D --> F([پایان])

پیکان و برچسب اتصال

--> پیکان معمولی می‌سازد. برای نوشتن توضیح روی مسیر، متن را میان دو خط تیره یا داخل | | قرار بده.

برچسب مسیرویرایش در ادیتور
flowchart LR
    A[ورود کاربر] --> B{حساب فعال است؟}
    B -- بله --> C[داشبورد]
    B -- خیر --> D[بازیابی حساب]
    D -. ایمیل تأیید .-> C

گروه‌بندی با subgraph

برای دسته‌بندی اجزای مرتبط از subgraph استفاده کن. این قابلیت در نمودارهای معماری و فرایندهای بزرگ بسیار مفید است.

گروه‌بندی سرویس‌هاویرایش در ادیتور
flowchart LR
    subgraph Client[کلاینت]
      U[کاربر] --> W[وب‌اپ]
    end
    subgraph Server[سرور]
      A[API] --> D[(دیتابیس)]
    end
    W --> A

خطاهای رایج

  1. شناسهٔ تکراری: هر گره بهتر است شناسهٔ یکتا مثل A یا payment داشته باشد.
  2. متن پیچیده بدون کوتیشن: متن‌های دارای پرانتز یا علامت‌های خاص را داخل کوتیشن بنویس.
  3. استفاده از نیم‌فاصله در شناسه: نیم‌فاصله و متن فارسی را برای برچسب نگه دار، نه شناسهٔ گره.
  4. نمودار بیش از حد شلوغ: بخش‌ها را با subgraph جدا کن یا جهت را به LR تغییر بده.
پیشنهاد: شناسه‌ها را انگلیسی و کوتاه انتخاب کن، اما متن قابل مشاهدهٔ گره‌ها را کاملاً فارسی بنویس.
