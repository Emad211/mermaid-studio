اولین فلوچارت

هر نمودار با نوع آن شروع می‌شود. در نمونهٔ زیر، TD یعنی نمودار از بالا به پایین چیده شود. متن داخل براکت، عنوان گره است و --> دو گره را به هم وصل می‌کند.

flowchart.mmdویرایش در ادیتور
flowchart TD
  A[ثبت درخواست] --> B{اطلاعات کامل است؟}
  B -- بله --> C[پردازش درخواست]
  B -- خیر --> D[تکمیل اطلاعات]
  D --> B
  C --> E[پایان]

اولین نمودار توالی

در Sequence Diagram هر شرکت‌کننده با participant یا actor معرفی می‌شود. فلش توپر برای درخواست و فلش خط‌چین برای پاسخ مناسب است.

sequence.mmdویرایش در ادیتور
sequenceDiagram
  autonumber
  actor U as کاربر
  participant W as وب‌اپ
  participant A as API
  U->>W: ثبت فرم
  W->>A: POST /requests
  A-->>W: 201 Created
  W-->>U: نمایش نتیجه
نکته: متن فارسی داخل گره‌ها و پیام‌ها پشتیبانی می‌شود؛ اما خود کلمات کلیدی Mermaid مانند flowchart و sequenceDiagram باید انگلیسی باقی بمانند.
